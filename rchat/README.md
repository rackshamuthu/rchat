## 🌟 தமிழ் விளக்கம் (Tamil Overview)

**Rchat** என்பது வாட்ஸ்அப் (WhatsApp) செயலியை முழுமையாக ரிவர்ஸ்-இன்ஜினியரிங் செய்து, **சுமிஸ் (Sumis)** பிராண்டின் கீழ் பிசினஸ் மற்றும் பர்சனல் பயன்பாட்டிற்காக உருவாக்கப்பட்ட ஒரு அதிநவீன மொபைல் மெசேஜிங் ஆப் ஆகும்.

### 🚀 முக்கிய அம்சங்கள் (Core Features):
1. **மொபைல் எண் லாகின் & OTP சரிபார்ப்பு:**
   - 10 இலக்க மொபைல் எண் மூலம் லாகின் செய்தல்.
   - 6 இலக்க OTP சரிபார்ப்பு முறை (உடனடி டெமோ டெஸ்டிங்கிற்கு ஸ்கிரீனிலேயே OTP காட்டப்படும்).
2. **ப்ரொபைல் உருவாக்கம் (Profile Setup):**
   - பயனர் பெயர் (User Name), ப்ரொபைல் படம் (Avatar), வணிகப் பிரிவு (Business Category), மற்றும் பயோ (About / Status).
3. **நபர் A மற்றும் நபர் B நேரலை சாட்டிங் (Real-Time 1-on-1 Messaging):**
   - நபர் A மொபைலில் இருந்து நபர் B-க்கு மெசேஜ் அனுப்பினால், நொடிப் பொழுதில் Server-Sent Events (SSE) மூலம் நபர் B-க்கு சென்றடையும்.
   - ஆடியோ நோட்டிஃபிகேஷன் சவுண்ட் அலர்ட்.
4. **வாட்ஸ்அப் டிக் குறியீடுகள் (Delivery & Read Receipts):**
   - ஒற்றை சாம்பல் டிக் (`✓` Sent)
   - இரட்டை சாம்பல் டிக் (`✓✓` Delivered)
   - இரட்டை நீல நிற டிக் (`✓✓` Read)
5. **மல்டிமீடியா & ஃபைல்கள் பகிர்தல் (Rich Media Sharing):**
   - 📷 **புகைப்படங்கள் (Photos):** கேலரி அல்லது கேமராவிலிருந்து படங்களை அனுப்பி, ஃபுல் ஸ்கிரீன் லைட்பாக்ஸில் பார்த்தல்.
   - 🎵 **மியூசிக் & ஆடியோ (Audio Files):** MP3 மற்றும் பாடல்களை அனுப்பி, வாட்ஸ்அப் ஆடியோ பிளேயர் மூலம் நேரடியாக பிளே செய்து கேட்டல்.
   - 📄 **ஆவணங்கள் & ஃபைல்கள் (Documents):** PDF, Word, ZIP போன்ற ஆவணங்களை டவுன்லோட் வசதியுடன் பகிர்தல்.
   - 🎙️ **குரல் செய்தி (Voice Notes):** மைக் பட்டன் மூலம் ஆடியோ மெசேஜ் அனுப்புதல்.
6. **வாட்ஸ்அப் தாவல்கள் (WhatsApp Tabs Layout):**
   - 💬 **Chats:** அனைத்து உரையாடல்கள், படிக்காத மெசேஜ்கள் (Unread Badge), ஃபில்டர்கள் (All, Unread, Business).
   - ⭕ **Updates / Status:** 24 மணி நேர வாட்ஸ்அப் ஸ்டேட்டஸ் கதைகள் (Stories).
   - 📞 **Calls:** ஆடியோ மற்றும் வீடியோ அழைப்புகள் வரலாறு மற்றும் காலிங் ஸ்கிரீன்.
   - 👥 **Business Hub (Sumis):** புராடக்ட் கேட்டலாக் (Product Catalog), விரைவு பதில்கள் (Quick Replies), பிசினஸ் ப்ரொபைல்.
7. **பிரத்தியேக கலர் தீம்கள் (Sumis Exclusive Themes):**
   - Sumis Emerald (எமரால்டு டீல்)
   - Midnight Teal (நைட் டீல்)
   - Royal Indigo (ராயல் இண்டிகோ)
   - Classic Green (பாரம்பரிய வாட்ஸ்அப் பச்சை)

## 📱 மொபைலில் இன்ஸ்டால் செய்து APK ஃபைல் பெறுவது எப்படி?

### வழிமுறை 1: நேரடி மொபைல் இன்ஸ்டாலேஷன் (PWA - 1 நிமிடம்)
1. உங்கள் கணினியில் `start.bat` ஃபைலை இயக்கவும் (அல்லது `node server.js`).
2. டெர்மினலில் உங்கள் லோக்கல் வைஃபை ஐபி முகவரி காட்டப்படும் (எ.கா: `http://192.168.1.8:3000`).
3. உங்கள் ஆண்ட்ராய்டு மொபைலில் Chrome பிரவுசரில் அந்த முகவரியை திறக்கவும்.
4. பிரவுசரின் மெனுவில் **"Add to Home Screen"** அல்லது **"Install Rchat"** என்பதைத் தட்டவும்.
5. இப்போது உங்கள் மொபைல் மெனுவில் **Rchat** செயலி நேட்டிவ் ஆப் போல தனி லோகோவுடன் இன்ஸ்டால் ஆகிவிடும்!

### வழிமுறை 2: GitHub Actions மூலம் நேரடி `.apk` ஃபைல் டவுன்லோட் (Cloud APK Build)
இந்த ப்ராஜெக்ட்டில் `.github/workflows/build-apk.yml` ஆட்டோமேஷன் ஃபைல் சேர்க்கப்பட்டுள்ளது:
1. இந்த ப்ராஜெக்ட் ஃபோல்டரை உங்கள் GitHub அக்கவுண்ட்டில் ஒரு புது ரெபாசிட்டரியாக push செய்யவும்.
2. GitHub-ன் **Actions** டேப்பில் தானாகவே Android SDK இயங்கி **`Rchat-Sumis-debug.apk`** ஃபைலை பில்ட் செய்து கொடுத்துவிடும்.
3. அதை 1-கிளிக்கில் டவுன்லோட் செய்து எந்த ஆண்ட்ராய்டு போனிலும் இன்ஸ்டால் செய்து கொள்ளலாம்!

### வழிமுறை 3: லோக்கல் ஆண்ட்ராய்டு ஸ்டுடியோ மூலம்
`android/` ஃபோல்டரில் முழுமையான Android Gradle Project உள்ளது:
- ஆண்ட்ராய்டு ஸ்டுடியோவில் `android` ஃபோல்டரைத் திறந்து `Build > Build Bundle(s) / APK(s) > Build APK(s)` கொடுத்தால் உங்கள் கணினியிலேயே `.apk` ஃபைல் தயாராகிவிடும்.
